📁 tirth_data.js ફાઈલ મેનેજમેન્ટ

આ વેબ એપ તમારા GitHub રિપોઝિટરીમાં રહેલી tirth_data.js ફાઈલ અને images/ ફોલ્ડરમાંથી તીર્થસ્થાનોના નામ તથા ફોટા વાંચે છે. નવા ઉમેરેલા તીર્થસ્થાનો ફાઈલમાં સેવ કરવા નીચેના વિકલ્પો વાપરો:

૧. અપડેટ થયેલી tirth_data.js ફાઈલ ડાઉનલોડ કરો

નવા ઉમેરેલા તીર્થસ્થાનો અને ફોટા સાથેની તૈયાર ફાઈલ ડાઉનલોડ કરીને GitHub માં મૂકો.

૨. કોમ્પ્યુટરની લોકલ ફાઈલ સાથે સીધું લિંક કરો

એકવાર તમારા PC માં રહેલી tirth_data.js પસંદ કરશો એટલે નવું નામ ઉમેરતા જ તેમાં ઓટોમેટિક સેવ થશે.

૩. સીધું GitHub રિપોઝિટરીમાં ઓટો-સેવ (વૈકલ્પિક)
